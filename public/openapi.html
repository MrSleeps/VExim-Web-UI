Download OpenAPI specification:

VExim Support: support@veximweb.com License: Proprietary

API for managing VExim domains with Sanctum token-based authentication. All requests require a valid Bearer token.

Domains

Domain management operations

List all domains

Get a paginated list of domains. System admins see all domains, domain admins see only their assigned domains.

Required Token Ability: domains:view

Authorizations:
bearerAuth
query Parameters
type
string
Enum: "local" "alias" "remote"

Filter by domain type

status
string
Enum: "enabled" "disabled"

Filter by domain status

search
string

Search term for domain names

page
integer >= 1
Default: 1

Page number for pagination

per_page
integer [ 1 .. 100 ]
Default: 15

Number of items per page

sort_by
string
Default: "domain"
Enum: "domain" "type" "created_at" "domain_id"

Field to sort by

sort_order
string
Default: "asc"
Enum: "asc" "desc"

Sort order

Create a new domain

Create a new domain. Only system administrators can create domains.

Required Token Ability: domains:create

Authorizations:
bearerAuth
Request Body schema: application/json
required
domain
required
string^[a-z0-9.-]+\.[a-z]{2,}$

Domain name (lowercase, valid format)

type
required
string
Enum: "local" "alias"

Domain type: local (mail handled locally) or alias (forward to primary domain)

primary_domain_id
string

Required for alias domains. Primary domain ID or name

maildir
string

Mail directory path (default: /var/mail/{domain})

uid
integer

User ID for mail files (default: 8)

gid
integer

Group ID for mail files (default: 8)

max_accounts
integer >= 1

Maximum number of email accounts (null = unlimited)

quotas
integer >= 0

Storage quota in MB (0 = unlimited)

maxmsgsize
integer >= 0

Maximum message size in bytes (0 = system default)

spamassassin
boolean

Enable SpamAssassin spam filtering

sa_tag
integer >= 0

Spam tag score (required if spamassassin is true)

sa_refuse
integer >= 0

Spam refuse score (required if spamassassin is true)

avscan
boolean

Enable virus scanning

blocklists
boolean

Enable blocklist filtering

admin_user_id
string

User ID or email to assign as initial administrator

Responses

Production Server

https://api.veximweb.com/api/v1/domains

Staging Server

https://staging-api.veximweb.com/api/v1/domains

Local Development Server

http://localhost:8000/api/v1/domains
